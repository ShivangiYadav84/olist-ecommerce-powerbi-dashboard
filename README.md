# Olist E-Commerce Sales Dashboard

Power BI sales dashboard on the Olist Brazilian E-Commerce dataset (Kaggle).



![Dashboard](Screenshot%202026-10-17%20150021.png)



## Tools
Power BI, Power Query, DAX

## What I did
- Cleaned and merged 8 tables in Power Query
- Built a star-schema model with a Date table
- Created DAX measures: Total Revenue, Total Orders, AOV
- Built KPI cards, monthly revenue trend, top 10 categories and a Year slicer

## Key insights
- 12.43M revenue from 96K delivered orders, AOV 128.82
- health_beauty and watches_gifts are top categories
- Revenue grew through 2017 and peaked in Nov 2017 (likely Black Friday)
